# WarAlarm 🇺🇦

Персональная тревога по целям для Харькова: сервер читает Telegram-каналы
мониторинга, фильтрует угрозы для нужного района и даёт собственный сигнал
тревоги на телефон (Android / Google Play) и Windows.

## Стек

- **Язык:** C# / .NET 9 — весь проект на одном языке.
- **Чтение Telegram:** [WTelegramClient](https://github.com/wiz0u/WTelegramClient) (userbot).
- **Сервер (позже):** ASP.NET Core / Worker Service.
- **Push (позже):** Firebase Cloud Messaging.
- **Клиенты (позже):** .NET MAUI (Android + Windows из одного кода).

## Дорожная карта

| Фаза | Что | Статус |
|---|---|---|
| **0. Ридер** | Консоль читает каналы, фильтрует «Харків», печатает | ✅ готово |
| **1. Локальная тревога** | Разбор типа цели + звук сирены на ПК | ⬜ |
| **2. Сервер + push** | Ридер на сервере, Firebase | ⬜ |
| **3. MAUI-клиенты** | Android + Windows ловят push → сирена | ⬜ |
| **4. Play-полиш** | Ночные full-screen тревоги, публикация | ⬜ |

## Запуск ридера (Фаза 0)

1. Получи `api_id` и `api_hash` на <https://my.telegram.org> → *API development tools*.
2. В папке `src/Reader` скопируй `secrets.example.txt` → `secrets.local.txt`
   и впиши свои значения (файл в `.gitignore`, в репозиторий не попадёт).
3. Убедись, что твой Telegram-аккаунт **подписан** на нужные каналы мониторинга.
4. Запуск:
   ```
   cd src/Reader
   dotnet run
   ```
   При первом входе Telegram пришлёт код — введи его в консоли (сессия
   сохранится в `WTelegram.session`, дальше без кода).

## Быстрый запуск (Windows)

Двойной клик по **`start.bat`** в корне — запустит живой режим и сам откроет карту.
Пока окно открыто: карта обновляется по постам каналов, сирена на ПК, push на телефон.

## Команды

```
dotnet run                 # боевой режим: слушает каналы, тревога + сирена + push
dotnet run -- check        # прогнать свежие посты всех каналов через тревогу (без ожидания)
dotnet run -- sim          # проиграть тревогу на реальных сэмплах СО ЗВУКОМ
dotnet run -- sounds       # послушать все звуки сирены по типам угроз
dotnet run -- track        # ДЕМО: жизненный цикл угрозы (ETA, стадии, звук) + карта map.html
dotnet run -- uamap        # ДЕМО: карта всей Украины стрелками (шахеды короткие, ракеты длинные)
dotnet run -- ai           # тест настоящего ИИ (Claude) на сэмпле — нужен ai_api_key в secrets.local.txt
dotnet run -- stats        # статистика тревог (по городам, типам, дням) из alarms.csv
dotnet run -- channels Ки  # список каналов с @username (фильтр по названию)
dotnet run -- dump @канал 50   # вытянуть последние посты канала
dotnet run -- kh [район]   # оффлайн-разбор Харькова на сэмплах
dotnet run -- ky           # оффлайн-разбор Киева на сэмплах
dotnet run -- geo 50.05 36.30   # координаты → район
dotnet run -- push         # тест: отправить пробную тревогу на телефон
```

Настройки — в `settings.local.txt` (район, города, порог отбоя, `my_lat`/`my_lon` для дома
на карте), меняются без пересборки.
Push на телефон — через приложение **ntfy** (топик в `secrets.local.txt` как `ntfy_topic=`).

## Карта угроз и стадии подлёта

Ридер ведёт каждую цель по стадиям: **наближається** (редкие «пики», учащаются по мере
подлёта) → **на підльоті** (вой) → **над районом** → **приліт** (взрыв) → **пройшла далі**.
Расстояние и ETA считаются по названиям мест из каналов (`ThreatGeo`) и скорости типа цели.
Параллельно **по новостям рисуется `map.html`** — реальный контур Украины (как в
`design/index.html`), города, дом, метки целей по геокоду мест, траектории и живой обратный
отсчёт ETA (страница сама обновляется). Карту рисуют: `dotnet run` (live), `dotnet run -- sim`
(по сэмплам) и `dotnet run -- check` (по свежим постам каналов).
